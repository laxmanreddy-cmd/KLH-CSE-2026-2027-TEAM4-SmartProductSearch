# Algorithm completion order

Each numbered folder contains exactly two algorithm modules. The Java runtime implementation is in `backend/src/Algorithms.java` and the web application invokes the implementations through its API.

01. 01_Searching: KMP + LinearSearch\n02. 02_Basic_Sorting: BubbleSort + SelectionSort\n03. 03_Advanced_Sorting: InsertionSort + MergeSort\n04. 04_Divide_Conquer: QuickSort + HeapSort\n05. 05_Non_Comparison_Sorting: CountingSort + RadixSort\n06. 06_Trees: BSTSearch + AVLTree\n07. 07_Graph_Traversal: BFS + DFS\n08. 08_Shortest_Path: Dijkstra + BellmanFord\n09. 09_MST: Prim + Kruskal\n10. 10_Dynamic_Programming: FloydWarshall + LCS\n11. 11_Hashing: SeparateChaining + HashMapLookup\n12. 12_Greedy: ActivitySelection + FractionalKnapsack
